# SPEC_11 — актуальные SEO-пункты для портфолио

> Источник: [`docs/SPECS/SPEC_11.md`](./SPEC_11.md) — универсальный SEO-чеклист для коммерческих/e-commerce сайтов (100 пунктов, ориентирован на Яндекс + локальный бизнес). Ниже — только то, что реально применимо к **личному портфолио-сайту на Next.js** (не интернет-магазин, не локальный бизнес с адресом/графиком работы, без Яндекс-таргетинга). Часть пунктов адаптирована под контекст сайта (например: "товарная перелинковка" → "перелинковка между проектами").

Статус: **пройдено** (2026-08-04) — весь чеклист прогнан и реализован. Два пункта требуют ручного действия в Google Search Console (см. ниже), остальное сделано и проверено локальным продакшн-билдом (`next build` + `next start`).
