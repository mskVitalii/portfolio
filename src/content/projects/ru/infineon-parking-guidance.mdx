## Контекст

На кампусе Infineon в Дрездене сотни парковочных мест, разбросанных по нескольким зонам. До этого проекта компания рассматривала коммерческих поставщиков систем навигации по парковке — лучшее предложение обходилось в **€480 000 в год** на лицензии и обслуживание.

Альтернатива: собственная разработка.

## Что было построено

Полноценная система навигации по парковке — от железа до дашборда:

- **Embedded-прошивка** на C, работающая на IP-камерах — выполняет ANPR (автоматическое распознавание номеров) и подсчёт занятости без передачи видеопотоков по сети.
- **Python-микросервисы** агрегируют занятость зон, обрабатывают аутентификацию и обслуживают REST/WebSocket API.
- **Слой управления устройствами на C#** отвечает за подготовку камер, обновления прошивки и мониторинг состояния.
- **Дашборд на React + TypeScript** даёт службе безопасности и водителям карту доступных мест в реальном времени.

## Архитектура

```
┌──────────────────┐     MQTT      ┌────────────────────┐
│  IP-камера (C)    │ ────────────► │  Python-бэкенд      │
│  ANPR + подсчёт   │               │  (обработчик событий)│
└──────────────────┘               └────────┬───────────┘
                                            │ WebSocket
                                   ┌────────▼───────────┐
                                   │  Дашборд на React   │
                                   │  (карта в реальном  │
                                   │   времени)          │
                                   └────────────────────┘
```

Камеры выполняют распознавание локально (edge computing) — по сети передаются только события занятости, а не видео. Это снижает нагрузку на канал и снимает вопросы GDPR, связанные с централизованным хранением видео.

</ModeAware>

## Проблемы

**Мост между embedded и веб.** Написание C для камер с ограниченными ресурсами и последующая связка с React SPA потребовали чистой границы протокола. Вместо HTTP-поллинга выбрали MQTT, чтобы удержать задержку ниже 500 мс.

**Плавная деградация.** Если камера отключается, система не показывает устаревшие данные — зона помечается как «неизвестно», и дашборд отражает неопределённость, а не врёт.

**Мультитенантная конфигурация.** У разных парковок разная разметка. Подход «конфигурация как данные» означает, что добавление новой парковки — это JSON-файл, а не изменение кода.

## Результат

Система заработала на кампусе. **Сэкономлено €480 000 в год** по сравнению с предложением поставщика. Самостоятельно добавленная подсистема управления шлагбаумами обслуживает **8 000 зарегистрированных пользователей**, из них **3 000 — ежемесячно активные**.

## Что бы я сделал иначе

Структура MQTT-топиков росла органически и стала несогласованной между типами камер. Я бы определил схему топиков заранее как формальный контракт и версионировал её с самого начала.
