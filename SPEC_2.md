Да. Если твои партии и статистика находятся на Chess.com, их можно получать программно через официальный публичный API.

Сайт API:
[Chess.com Public API](https://www.chess.com/news/view/published-data-api?utm_source=chatgpt.com)

Что можно получить:

* Профиль пользователя
* Рейтинг по разным контролям времени (bullet, blitz, rapid, daily)
* Историю рейтингов
* Список партий по месяцам
* Последние партии
* Статистику побед/поражений
* Информацию о турнирах

Например:

```bash
curl https://api.chess.com/pub/player/mskvitalii
```

```bash
curl https://api.chess.com/pub/player/mskvitalii/stats
```

```bash
curl https://api.chess.com/pub/player/mskvitalii/games/2026/06
```

Если сайт на React + TypeScript, обычно делают так:

1. Backend (Go или Node) раз в несколько часов запрашивает Chess.com API.
2. Сохраняет данные в БД.
3. Frontend показывает данные из своей БД.

Так лучше, потому что:

* нет проблем с лимитами API;
* сайт работает быстрее;
* можно строить свою аналитику.

Интересные идеи для портфолио:

* График роста рейтинга по месяцам.
* Тепловая карта активности по дням.
* Лучшие победы по рейтингу соперника.
* Анализ дебютов (какими играешь чаще всего).
* Виджет "Current Blitz Rating".
* Автоматически обновляемый блок "Последняя партия".
